# Como avaliar os candidatos 📱

**1. Abra o seu link pessoal** (chegou no WhatsApp). Ele é só seu: não repasse.
Dica: no celular, use **"Adicionar à tela inicial"** para abrir como app.

**2. Avalie a equipe da vez.** Quando o admin abre uma equipe, ela aparece no topo como **Avalie agora · Equipe N**.
Toque num membro, dê as notas e use **Próximo da equipe**. Os outros candidatos ficam em **Outros candidatos**.
Cada dinâmica tem notas separadas: a nota de alguém na Dinâmica 1 não muda a da Dinâmica 2.

**3. Dê as notas com um toque**, de **1 a 5** em cada critério.
Não viu o suficiente, ou é muito próximo do candidato? Toque em **Não posso avaliar**.
Não acompanhou esse candidato? Use **Não posso avaliar este candidato** (marca todos de uma vez).
Toque no nome do critério (ⓘ) para ler a descrição.

**4. Pronto, já está salvo.** Não tem botão de enviar: cada toque é salvo na hora.
No topo aparece **Salvo ✓**. Se aparecer **Sem conexão**, pode continuar avaliando: as notas ficam guardadas
no celular e são enviadas sozinhas quando a internet voltar (mesmo se você fechar o app).

**5. Siga para o próximo** com **Próximo da equipe**. Na lista, ✓ marca quem você já avaliou.

**Pode mudar uma nota?** Sim, enquanto a avaliação estiver aberta: é só tocar em outra.
**Observação:** opcional, no fim da tela do candidato.
**Suas notas são individuais:** ninguém vê suas notas no app, só a comissão do PS.

Problema com o link? Fale com o admin do PS.
